# Harit PDF

Private, 100% browser-based PDF editor built for **Harit**.

Edit text, sign, highlight, draw, fill forms, merge, split, reorder, rotate, compress, and convert PDFs and images completely offline on your device. Files never leave your browser, with zero analytics, tracking scripts, or external servers.

Hosted on GitHub Pages at: https://haritpremrajput.github.io/harit-pdf-editor/
Repository: https://github.com/haritpremrajput/harit-pdf-editor

Built with pdf.js and pdf-lib. Fonts: DejaVu Sans, Dancing Script and Caveat (open licences).
